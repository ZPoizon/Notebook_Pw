# Aula 02 — HTML e CSS — Estrutura e apresentação

**Professor da disciplina:** Me. Deivison S. Takatu

> Registro temático de revisão, elaborado a partir dos projetos do semestre. A numeração é organizacional e não representa uma aula oficial ou data confirmada.

## Resumo
Compreender a separação entre conteúdo e apresentação; construir interfaces organizadas e adaptáveis. O conteúdo é relacionado ao projeto [Pwsite](https://github.com/ZPoizon/Pwsite), permitindo revisar a teoria junto à prática.

## Objetivos de aprendizagem
- Compreender os conceitos centrais de HTML e CSS.
- Identificar sua aplicação no código e na estrutura do projeto.
- Relacionar os conceitos à construção e manutenção de aplicações web.

## Conteúdo principal
- HTML semântico: títulos, seções, formulários e botões.
- atributos id e class para identificação e estilo.
- CSS: seletores, cascata, especificidade, box model, Flexbox e Grid.
- viewport e media queries para responsividade.
- acessibilidade por rótulos e elementos nativos.

## Aplicação prática no projeto
No Anime Quiz Master, o HTML organiza as telas de início, carregamento, perguntas e resultados. O CSS define os cartões, a hierarquia visual e os estados da interface.

## Metodologia e recursos
Leitura de código-fonte, revisão da documentação técnica, análise da estrutura do repositório e exercícios de implementação. Os exercícios abaixo são propostas de revisão, não atividades oficiais atribuídas ao professor.

## Atividades de revisão
1. Criar uma página com cabeçalho, conteúdo e rodapé.
2. estilizar cartões.
3. verificar a leitura em telas pequenas.
